Apple Calendar on Mac

Open calendar app

If the link opens a subscription dialog, review it and confirm. If it does not, add it manually:

  1. Open Calendar. Choose File > New Calendar Subscription.
  2. Paste the feed URL and select Subscribe.
  3. Name it JTS Demo. Choose On My Mac for local testing, or iCloud to make the subscription available on your Apple devices.
  4. Set Auto-refresh to Every 5 minutes if available, then select OK.

For localhost, Calendar must run on the computer serving the feed. For iCloud or other devices, use a reachable deployed URL.

Apple Calendar on iPhone or iPad

Open calendar app

Use a deployed URL reachable from your device. If the link does not show a subscription prompt:

  1. Open Calendar, then tap Calendars.
  2. Tap Add Calendar > Add Subscription Calendar.
  3. Paste the feed URL, then tap Find (or Subscribe, depending on your OS version).
  4. Name it JTS Demo. Choose iCloud under Account to share it across your Apple devices, then tap Done on iOS/iPadOS 26 or later (Add on older versions). No username or password is required.
  5. Return to Calendars and make sure the subscription is selected.

Google Calendar in a desktop browser

Open Google Calendar
  1. Copy the public HTTPS feed URL above. Google must be able to fetch it without a login, VPN, or browser cookies.
  2. Open Google Calendar in a computer browser and sign in to the account you want to use.
  3. Next to Other calendars, select + > From URL. The button above opens that settings page directly.
  4. Paste the feed URL and select Add calendar.
  5. Return to the calendar and select the new calendar under Other calendars.

Use From URL, not the email-based Subscribe to calendar option. Google decides when to refresh external feeds; updates are not immediate.

Google subscription help

Google Calendar on Android, iPhone, or iPad

  1. On a computer, add the public feed in Google Calendar > Other calendars > + > From URL, using the same Google account as your phone.
  2. Open the Google Calendar app on your phone and allow the account to sync.
  3. Open the app's menu and make sure the new calendar is checked. Scroll or expand the calendar list if necessary.
  4. On Android, if it is still missing, open Settings in the Calendar app, select the subscribed calendar (use Show more if needed), and enable Sync if that option appears.

The Google Calendar mobile app cannot create a new URL subscription. Set it up in the desktop website first. Android apps other than Google Calendar may require their own ICS subscription support.

Outlook on the web or new Outlook

Open Outlook.com
  1. Open Calendar in Outlook.com, your work/school Outlook website, or new Outlook.
  2. Select Add calendar > Subscribe from web. Expand the left navigation if Add calendar is hidden.
  3. Paste the public HTTPS feed URL and name the calendar JTS Demo.
  4. Select Import or Save, as shown in your version. Because you chose Subscribe from web, this is a subscription, not a file import.
  5. Select the new calendar in the calendar list.

For the Outlook mobile app, add the feed through the website first using the same account. Mobile visibility varies by account and app version; use the web calendar if the subscription is not shown. Organization policy may block external calendars.

Microsoft subscription help

Classic Outlook on Windows

  1. Open the Calendar view.
  2. On the ribbon, choose Home > Add Calendar > From Internet. Some versions label this Open Calendar > From Internet.
  3. Paste the feed URL and select OK.
  4. When asked whether to add the Internet Calendar and subscribe to updates, select Yes.
  5. Select the new calendar in the left-hand list. Use Send/Receive All Folders to request a refresh.

This applies to classic Outlook, not the redesigned new Outlook. If From Internet is unavailable, use the Outlook web instructions instead. Do not open a downloaded .ics file as a substitute for subscribing.

Thunderbird on Windows, Mac, or Linux

  1. Open Calendar. In the calendar list, right-click and choose New Calendar (or use File > New > Calendar).
  2. Choose On the Network.
  3. Enter the feed URL as the Location. Leave the username empty; choose This location doesn't require credentials if offered.
  4. Select Find Calendars or Next. Choose iCalendar (ICS) if a format is requested.
  5. Select the discovered calendar, name it JTS Demo, and finish the subscription wizard.
  6. In calendar properties, keep it Read-only and choose a refresh interval. This demo feed does not accept edits.

Thunderbird can use localhost when it runs on the same computer as Termin Service. Wizard labels vary by version.

3. Check the subscription

Look for Test Termin on a Tuesday on or after 13 October 2026. In the Berlin timezone it runs from 13:15 to 14:15, including after clock changes.

The calendar is empty or cannot be added

Check that the feed URL is correct, the server is running, and the calendar is selected. Cloud providers need a publicly accessible URL with no authentication. Localhost only works on the computer serving the feed. If your view is before 13 October 2026, move to a later Tuesday.

The time has changed, but my app still shows the old time

The feed suggests a five-minute minimum refresh interval, but calendar apps may ignore or override it. Subscriptions refresh on the calendar provider's schedule. Refresh manually where supported, or wait. Outlook updates can take more than 24 hours; Google also controls its own polling. The feed's no-store header does not force calendar apps to refresh immediately.

What does the event's synchronization timestamp mean?

Open Test Termin and read its description. "Last synchronized (feed generated)" shows when the server generated that copy of the feed, in UTC. It updates on every feed request. It is not proof of when your calendar app synchronized; an old timestamp indicates that you are still viewing an older copy.

I see duplicate events

Keep one subscription and remove any extra subscriptions or one-time imports. The feed uses a stable event identifier, but importing the file separately may create another copy.

How do I remove the demo?

Unsubscribe from or delete the JTS Demo calendar in your app's calendar list or settings. Hide it by unchecking it if you only want to stop displaying it. Removing the subscription does not affect other calendars.
